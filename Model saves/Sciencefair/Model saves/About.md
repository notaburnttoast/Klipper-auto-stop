# Model saves
Model saves will each be in a folder with a name of model layer size. In the folder the model will be saved as best.pt and last.pt. There will also be a grid of 4x4 images with the model perdictions at a cut off of 0.8 (80%)
## example:
### L2
- best.pt
- last.pt
### L3
- best.pt
- last.pt
