# Model saves
Model saves will each be in a folder with a name of model layer size and number of cov2d. In the folder the model will be saved as best.pt and last.pt. There will also be a grid of images with the model perdictions at a cut off of 0.8 (80%)
## example:
### L2 N3
- best.pt
- last.pt
- images
- - prediction epoch num.png
### L3 N6
- best.pt
- last.pt
- images
- - prediction epoch num.png
